# 農場経営ゲーム

## 概要

本ゲームは、30日間で作物を育てながらスコアを競う農場経営シミュレーションゲームです。

プレイヤーは畑に作物を植え、日数を進めながら作物を成長させます。成長した作物は自動的に収穫され、その売却額が所持金として加算されます。限られた期間内に効率よく作物を育て、できるだけ高いスコアを獲得することを目指します。

### 1. 必要ライブラリのインストール

```bash
pip install pygame
```

### 2. ゲーム起動

```bash
python main.py
```

---

## ゲームの流れ

1. タイトル画面からゲームを開始する
2. Bagから植える作物を選択する
3. 畑をクリックして作物を植える
4. Sleepボタンで日付を進める
5. 作物が成長すると自動で収穫される
6. Shopで新しい種を購入する
7. 30日目終了後にスコアが表示される
8. ハイスコアは保存され、次回以降も確認できる

---

## 操作方法

### タイトル画面

- Start : ゲーム開始

### ゲーム画面

- Bag : 作物選択画面を開く
- Shop : 種を購入する
- Sleep : 日付を1日進める
- 畑クリック : 選択中の作物を植える

### Bag

植える作物を選択できます。

- 小麦
- トマト
- じゃがいも

### Shop

種を購入できます。

| 作物 | 種価格 |
| ------ | ------ |
| 小麦 | 50G |
| トマト | 150G |
| じゃがいも | 300G |

---

## ゲームルール

- 初期所持金：0G
- 初期種：小麦×5
- 畑サイズ：3×3
- 作物を植えると種を1個消費する
- Sleepを押すと1日経過する
- 成長した作物は自動で収穫される
- 収穫した作物の価格が所持金へ加算される
- 30日経過でゲーム終了となる
- 最終所持金をスコアとして記録する
