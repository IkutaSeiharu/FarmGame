# 農業シミュレーションゲーム

## 概要

本ゲームは、30日間で作物を育てながらハイスコアを目指す農場シミュレーションゲームです。

プレイヤーは畑に作物を植え、日数を進めながら作物を育てます。成長した作物は自動的に収穫され、売却額が所持金として加算されます。30日終了時の所持金をスコアとして競います。

---

## 開発環境

- Python 3.13
- Pygame 2.6.1
- Visual Studio Code
- GitHub

---

## 起動方法

### ライブラリのインストール

```bash
pip install pygame
```

### ゲームの起動

```bash
python main.py
```

---

## ゲームの流れ

1. タイトル画面からゲームを開始する
2. Bagから植える作物を選択する
3. 畑に作物を植える
4. Sleepで日付を進める
5. 成長した作物を自動収穫する
6. Shopで種を購入する
7. 30日経過でゲーム終了
8. スコア画面を表示する
9. ハイスコアを保存する

---

## 操作方法

### タイトル画面

- Start：ゲーム開始
- High Score：ハイスコア確認

### ゲーム画面

- Bag：植える作物を選択
- Shop：種を購入
- Sleep：1日進める
- 畑クリック：選択中の作物を植える

### Bag

所持している種を選択できます。

- 小麦
- トマト
- じゃがいも

### Shop

種を購入できます。

| 作物 | 種価格 |
|-------|-------|
| 小麦 | 50G |
| トマト | 150G |
| じゃがいも | 300G |

---

## ゲームルール

- 初期所持金：0G
- 初期種：小麦×5
- 畑サイズ：3×3
- 作物を植えると種を1個消費
- Sleepを押すと1日経過
- 作物は成長後に自動収穫
- 収穫した作物は自動で売却
- 所持金がスコアになる
- 30日目終了後にゲームオーバー

---
